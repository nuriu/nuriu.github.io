# Nuri Uzunoğlu — Digital Product Portfolio

A sophisticated, high-performance portfolio showcasing sleek digital tools built with a focus on clarity, intention, and craftsmanship.

## 🚀 Technologies

- **Framework**: [Astro 5](https://astro.build/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (with custom glassmorphism utilities)
- **Content**: [MDX](https://mdxjs.com/) for product data and collections
- **Typography**: Inter & Outfit (Google Fonts)
- **Icons**: Lucide-inspired SVG components

## 🛠️ Project Structure

```text
/
├── public/          # Static assets (logos, mockups)
├── src/
│   ├── components/  # Reusable Astro components (Hero, ProductSection, etc.)
│   ├── content/     # MDX files for product data (Numera, Notio)
│   ├── layouts/     # Base layouts for consistent styling
│   ├── pages/       # Route-specific pages
│   └── styles/      # Global CSS and Tailwind configuration
└── package.json
```

## 🧞 Commands

All commands are run from the root of the project:

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Build your production site to `./dist/` |
| `npm run preview` | Preview your build locally before deploying |

## ✨ Design Principles

- **Sophisticated Dark Aesthetic**: Deep backgrounds with vibrant primary accents.
- **Glassmorphism**: Layered transparency using backdrop filters and subtle borders.
- **Micro-animations**: Smooth transitions and scroll-reveal effects for an interactive feel.
- **Responsive**: Fully optimized for mobile, tablet, and desktop experiences.
